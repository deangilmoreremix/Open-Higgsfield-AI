# Plan: Integrate CutAI AI Storyboarder Application

## Goal
Create a full AI Storyboarder application based on the CutAI repo, integrating its complete feature set (AI script generation, shot breakdowns, mood analysis, storyboard canvas, etc.) while maintaining a promotional landing page UI design. The application will include a hero section, feature showcase, shot types, example scenes, and CTA leading to the full CutAI editor interface. Implement client-side features where possible, with placeholders for server-dependent elements.

## Scope
- **Full CutAI Feature Set**: AI script generation, shot-by-shot breakdown, mood analysis, soundtrack vibes, drag-and-drop storyboard canvas, visual timeline, inline editing, PDF export, project management.
- **UI Design**: Use the provided promotional page design with hero banner, feature grid, shot types, example scenes, and CTA button.
- **Client-Side Implementation**: Core UI and logic in vanilla JS; simulate AI features with mocks for script generation and analysis.
- **Integration**: Add as "AI Storyboarder" in the side menu, with router and app hub integration.
- **Constraints**: Preserve the clean, dark aesthetic; ensure responsive design; keep iframe isolation if needed for complex UI.

## CutAI Features to Integrate

### Core Features:
1. **AI Script Generation**: Generate screenplays from genre/premise
2. **Shot-by-Shot Breakdown**: Analyze scenes into individual shots with camera details
3. **Storyboard Canvas**: Drag-and-drop scene cards with mood gradients
4. **Mood Analysis**: 4D scoring (tension/emotion/energy/darkness) with graphs
5. **Soundtrack Vibes**: Genre/tempo/instruments/reference tracks per scene
6. **Visual Timeline**: React Flow-powered timeline with scene connections
7. **Inline Editing**: Edit scenes inline with regeneration
8. **Project Management**: Create/list/duplicate/delete projects
9. **Export**: JSON and PDF with mood bars and shot tables

### UI Design Structure:
- Use the provided StoryboardPage code as the base template, preserving color scheme and design concepts
- Hero section with CutAI branding and description
- Features grid showcasing CutAI capabilities (8 features)
- Shot types section with professional compositions
- Example scenes showing AI-generated breakdowns
- CTA button to launch the full CutAI editor
- Maintain dark aesthetic, blur effects, gradient backgrounds, and responsive grid layouts

### UI Components:
1. **Hero Section**: Promotional banner with title and description
2. **Features Grid**: Showcase 8+ CutAI capabilities
3. **Shot Types Display**: Professional shot type badges
4. **Example Scenes**: Sample AI-generated scene breakdowns
5. **CTA Button**: Launch full CutAI editor

### Editor Interface (Full Implementation):
1. **Script Input**: Genre/premise to screenplay generation
2. **Scene Parser**: Break scripts into structured scenes
3. **Shot Analyzer**: Generate camera angles, movements, duration
4. **Mood Calculator**: 4D mood analysis per scene
5. **Soundtrack Generator**: AI music suggestions
6. **Canvas Editor**: Drag scene cards, reorder
7. **Timeline View**: Visual connections and navigation
8. **Regeneration**: One-click scene re-analysis
9. **PDF Export**: Formatted storyboard documents

Total: ~25 features focused on CutAI's core AI storyboard functionality.

## Implementation Approach
- **Architecture**: Create CutAIPage.js based on the provided StoryboardPage code, adapted for CutAI features. Use the exact UI structure: hero, features grid, shot types, example scenes, CTA. Implement CutAI editor as a modal or full page with storyboard functionality.
- **State Management**: Use JS objects for projects, scripts, scenes, shots, mood data. Persist to localStorage.
- **UI Components**: Modify the StoryboardPage template to showcase CutAI features instead of basic storyboard. Build editor with Canvas for mood graphs, DOM for drag-and-drop, simulated timeline.
- **AI Simulation**: Mock LLM calls for script generation and analysis; use placeholder data for mood/soundtrack.
- **Rendering**: Use Canvas for mood graphs, DOM manipulation for canvas operations, CSS for animations.
- **Modularity**: Separate functions for script parsing, scene analysis, mood calculation, export.
- **Testing**: Browser testing with console logs for AI placeholders.
- **Compatibility**: Modern browsers with Canvas support.

   - Add 4D mood scoring with Canvas graphs.

5. **Phase 5: Soundtrack & Export** (1-2 days)
   - Add soundtrack suggestions UI.
   - Implement JSON/PDF export with mood data.

   - Add project CRUD operations.
   - Test full workflow, add animations and polish.

## Risks & Mitigations
- **AI Simulation Complexity**: Mocking LLM calls; mitigate with realistic placeholder data and clear labeling.
- **UI Complexity**: Many components in one page; mitigate with modular functions and clean HTML structure.
- **Canvas Performance**: Mood graphs and timeline rendering; mitigate with efficient drawing and lazy loading.
- **Browser Compatibility**: Canvas and drag-and-drop; ensure fallbacks for older browsers.

## Timeline Estimate
- Total: 7-9 days (1-2 days per phase).
- Dependencies: None (client-side only).
- Validation: Test in browser after each phase, verify drag-and-drop and export.
