# Plan: Integrate Client-Side Video Editing Features into TimelineEditorPage

## Goal
Transform the TimelineEditorPage component from a basic mockup into a full-featured video editing system using vanilla JavaScript, running entirely client-side in an iframe. Integrate ~80 video editing features from CineGen, LTX-Desktop, rendiv, timeline-studio, and chatvideo-yucut repos, excluding all server-dependent, AI model, or hardware-specific elements.

## Scope
- **Client-Side Only**: No external APIs, server calls, AI model inference, GPU acceleration, or telemetry. Everything must run in the browser using DOM, Canvas, CSS, and JS event handling.
- **Vanilla JS**: Implement in the embedded script of TimelineEditorPage.js, within an iframe for isolation.
- **Core Focus**: Video editing UI, logic, and manipulation (timeline, clips, tools, animations, transitions, export simulation).
- **Exclusions**: Real AI generation, FFmpeg rendering, external services, hardware-specific features.

## Features to Integrate (Grouped by Category)
Based on the filtered client-side features:

### 1. Timeline Core (~15 features)
- Multi-track timeline (unlimited tracks, layer stacking)
- Sequence/series/loop/freeze components
- Clip manipulation (add/move/trim/split/delete/copy)
- Keyframe animation system
- Time synchronization and drag-to-debug
- Batch/ripple editing

### 2. Editing Tools (~10 features)
- 10 editing tools (Select, Blade, Ripple, Roll, Slip, Slide, Music, Fill Gap, Extend, Mask)
- Transitions (fade, slide, wipe, dissolve)
- 3D camera movements (shake, zoom, dolly, orbit)

### 3. UI Components (~15 features)
- Dual viewer (source/timeline panes)
- Transport controls (play/pause/scrub)
- Waveform display (Canvas-based)
- Track management (add/delete/reorder/mute/solo/lock)
- Proxy toggle
- Multi-language UI (15 languages, RTL)
- Keyboard shortcuts

### 4. Media & Elements (~8 features)
- Elements library (4 categories, reference display)
- Media import (drag-and-drop, tagging)
- HTML animation IDE
- Speech-to-subtitles UI
- One-click speech error editing
- Subtitles engine

### 5. Animation & Effects (~10 features)
- Keyframe system for properties
- Interpolation, easing, spring functions
- 3D movements
- HTML animations
- Batch animations

### 6. Export & Preview (~8 features)
- Multi-platform export UI (presets)
- Basic rendering (Canvas simulation)
- Real-time preview
- Filmstrip thumbnails
- Frame capture

### 7. Advanced UI Systems (~8 features)
- Plugin system UI
- MCP protocol UI
- Agent workflow UI
- Interactive editor (drag/resize)

- Async control

### 8. Chat & Assistance (~6 features)
- Basic chat UI
- Multi-language support

- Timestamp linking

Total: ~80 features across 8 categories.

## Implementation Approach
- **Architecture**: Extend the existing iframe HTML/JS in TimelineEditorPage.js. Use DOM for UI, JS objects for state, Canvas for waveforms/thumbnails, CSS for animations/transitions.
- **State Management**: Expand the `state` object with new properties (e.g., tracks, keyframes, elements). Use arrays/objects for clips, keyframes.
- **Event Handling**: Add mouse/keyboard event listeners for tools, scrubbing, drag operations.
- **Rendering**: Use requestAnimationFrame for smooth animations, Canvas for visual elements.
- **Modularity**: Organize JS into functions for each category (e.g., `renderTimeline()`, `handleTools()`).
- **Testing**: Manual testing in browser; add console logs for debugging.
- **Compatibility**: Ensure works in modern browsers; use polyfills if needed for older Canvas support.

## Implementation Steps (Phased)
1. **Phase 1: Timeline Core** (1-2 days)
   - Extend HTML for multi-track layout.
   - Implement clip objects and positioning.
   - Add basic playback and scrubbing.

2. **Phase 2: Editing Tools & UI** (2-3 days)
   - Add tool buttons and event handlers.
   - Implement transitions and camera movements.
   - Build dual viewer and transport controls.

3. **Phase 3: Animation & Effects** (1-2 days)
   - Add keyframe system.
   - Integrate interpolation and easing.

4. **Phase 4: Media & Elements** (1-2 days)
   - Create elements library UI.
   - Add drag-and-drop media import.
   - Implement subtitles UI.

5. **Phase 5: Export & Advanced Systems** (1-2 days)
   - Add export UI and Canvas rendering.
   - Implement plugin/agent UIs.

6. **Phase 6: Chat & Polish** (1 day)
   - Add chat UI.
   - Test all features, add keyboard shortcuts, RTL support.

## Risks & Mitigations
- **Performance**: Large DOM with many clips; mitigate with virtualization (render only visible tracks).
- **Browser Limits**: Canvas memory for waveforms; use lazy loading.
- **Complexity**: 80 features in one script; mitigate with clear function organization.
- **Edge Cases**: Clip overlaps, keyframe conflicts; add validation logic.

## Timeline Estimate
- Total: 8-12 days (1-2 days per phase).
- Dependencies: None (client-side only).
- Validation: Test in browser after each phase.
