# Stock Media Integration Plan for Video Editor

## Current State Analysis
- ✅ **Pexels API key configured** in `.env.local`
- ✅ **Pexels service** created at `src/lib/pexels.js`
- ❌ **No media library component** for browsing stock media
- ❌ **No stock media integration** in video editor
- ❌ **No media module** for organizing media assets

## Goal
Implement a comprehensive stock media system that allows users to:
- Search and browse stock photos/videos from Pexels
- Import stock media into their projects
- Access a media library of user-uploaded + stock assets
- Use stock media in video editor like any other asset

## Implementation Plan

### Phase 1: Media Library Component
**Location:** `src/components/MediaLibrary.jsx`
**Features:**
- Tabbed interface: "My Media" | "Stock Photos" | "Stock Videos"
- Search bar with filters (orientation, size, color)
- Grid layout with lazy loading
- Drag & drop to editor
- Save to project functionality

### Phase 2: Stock Media Search Integration
**Location:** `src/components/StockMediaBrowser.jsx`
**Features:**
- Pexels API integration
- Real-time search with debouncing
- Pagination support
- Preview modal for assets
- Download and save to Supabase storage
- Add to user's media library

### Phase 3: Video Editor Integration
**Update:** `src/components/VideoEditor.jsx`
**Features:**
- Add media library button to toolbar
- Drag stock media directly onto canvas
- Context menu option to "Add Stock Media"
- Integrate with existing ElementToolbar

### Phase 4: Media Store Management
**Update:** `src/stores/VideoEditorStore.js` (add media methods)
**Features:**
- Cache stock media search results
- Track user's media assets
- Handle download/upload progress
- Sync with Supabase media_assets table

### Phase 5: API Enhancements
**Update:** `src/lib/api.js`
**Features:**
- Add `searchStockMedia()` method
- Add `importStockMedia()` method
- Add `getUserMediaLibrary()` method
- Integrate with existing Supabase media storage

## Technical Details
- **API Service**: Pexels API with 200 requests/hour free tier
- **Storage**: Supabase Storage for downloaded assets
- **Database**: media_assets table tracks user + stock media
- **UI**: Modal overlay for media browser (similar to templates)

## Success Criteria
